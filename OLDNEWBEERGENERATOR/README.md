# The Beer Name Generator

A fun web application that generates creative beer names with descriptions and specifications.

## Project Structure

This project has evolved over time, resulting in some duplicate files. Here's the current structure:

### Current Files (Use These)
- `index.html` - The main HTML file
- `js/script.js` - The current JavaScript implementation
- `css/styles.css` - The current CSS styles

### Deprecated Files (Can Be Removed)
- `lists/TheBeerNameGenerator.html` - Older version of the HTML
- `js/TheBeerNameGenerator.js` - Older version of the JavaScript
- `css/TheBeerNameGenerator.css` - Older version of the CSS
- `ExportToHTML.old/` - Old export directory
- `RandomTryOuts/` - Experimental code directory
- `BeerPotionGenerator.iml` - IntelliJ IDEA module file
- `DiscordBot.java` - Unrelated Java file
- `build.gradle`, `gradlew`, `gradlew.bat`, `gradle/` - Gradle build files

## Features

- Generate random beer names with detailed descriptions
- Auto-generation every 10 seconds
- Save your favorites
- Export your collection
- Customize the theme color
- Generate Midjourney prompts for beer label visualization

## How to Use

1. Open `index.html` in your web browser
2. Click "Serve Another" to generate a new beer name
3. Use the "Generate every 10s" button for automatic generation
4. Save your favorites with the "Favorite" button
5. Export your collection with the "Export Names" button
6. Customize the theme color with the color picker
